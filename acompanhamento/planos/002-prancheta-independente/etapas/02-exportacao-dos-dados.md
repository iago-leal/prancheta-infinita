# Etapa 02: exportação dos dados do artefato

## Objetivo

Extrair do banco e do armazenamento de arquivos do artefato todos os dados do autor, como a biblioteca, os quadros, as ajudas, os roteiros e os arquivos enviados, para um formato que o servidor da etapa 03 consiga importar.

## Critérios de conclusão

- [ ] O lugar onde a exportação fica guardada foi decidido com o autor, e nenhum dado pessoal vai para o Git sem a aprovação dele.
- [ ] A exportação contém todos os documentos das coleções listadas no inventário da etapa 01, e a contagem de quadros bate com a da biblioteca.
- [ ] Os arquivos enviados aos quadros, como imagens e PDFs, estão incluídos na exportação, cada um ligado ao quadro que o referencia.
- [ ] O formato da exportação está descrito num documento, com um exemplo.
- [ ] O artefato original continua intacto: nenhuma escrita foi feita no banco nem nos arquivos dele.
